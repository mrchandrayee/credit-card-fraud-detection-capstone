A **Credit Card Fraud Detection** capstone project that builds machine learning models to identify fraudulent transactions from highly imbalanced financial datasets.

## 🎯 Problem Statement

Predict fraudulent credit card transactions using machine learning — handling severe class imbalance (fraud is ~0.17% of transactions) to maximize detection while minimizing false positives.

## 🏗️ Approach

- **Logistic Regression** — Baseline classifier
- **Random Forest** — Ensemble tree model
- **XGBoost** — Gradient boosting
- **SMOTE** — Synthetic Minority Oversampling
- **Class Weighting** — Imbalance handling

## ✨ Features

- 💳 Fraud vs. legitimate transaction classification
- ⚖️ Class imbalance handling (SMOTE, class weights)
- 📊 ROC-AUC, Precision-Recall evaluation
- 🔍 Feature importance analysis
- 📓 Jupyter Notebook with full EDA
